Li8Z — CHIP-8 Emulator

An emulation of the classic CHIP-8 virtual machine. Built in Zig, prioritizing manual memory allocation, low-level pointer arithmetic, and zero-cost abstractions.

  • ARCHITECTURE: Complete reconstruction of the CHIP-8 instruction set. Thirty-five opcodes executed in sequence.
  • INTERFACE: Compiles to WebAssembly, rendering a 64x32 monochrome grid in any modern browser.
  • SIGNAL: Low-frequency square wave audio synthesis, triggered by keyboard input for tactile feedback.
  • Built with Zig, Raylib, and WebAssembly.

Brainoof — Esoteric Language Interpreter

An interpreter for a minimalist esoteric language. Rebuilt in Rust to enforce strict safety guarantees across a highly constrained instruction set.

  • DIALECT: A minimalist Brainfuck interpreter built on a single-pointer, 30,000-cell array.
  • IMPLEMENTATION: Written in Rust. Leverages strict ownership rules to eliminate safety overhead.
  • PARALLEL: Includes a clean Python implementation, serving as a secondary reference model.
