Li8Z — An Archaeology of 8-Bit Memory

A machine built to mimic a machine that never truly existed. Written in Zig, because memory should be managed by hand, like old photographs.

  • THE PROTOCOL: Reconstructed the entire CHIP-8 instruction set from yellowed documentation.
  • THE MEDIATION: Compiles to WebAssembly, allowing modern web browsers to pretend they are forty years younger.
  • THE SENSES: Emits low-frequency audio and accepts keyboard input, replicating the sterile joy of early computing.
  • Built with Zig, Raylib, and WebAssembly.

Brainoof — The Translation of Useless Systems

An interpreter for an esoteric programming language, written in Rust. It does not calculate taxes or manage databases. It exists only to prove that a machine can be driven to madness if given the right symbols.

  • THE COMPLIANCE: A pure Rust engine capable of running loops of complex, incomprehensible instructions like "bottles.bf".
  • THE ANCESTRY: Inspired by Krzysztof Gabis’s C interpreter, but rebuilt with the nervous caution of Rust.
  • THE BONUS: A Python implementation is included, in case the Rust compiler becomes too hostile.
